# Gobernanza y responsabilidades RACI sugeridas

**R** ejecuta; **A** responde/aprueba; **C** consulta; **I** informado. Son roles futuros, no personal ya designado.

| Decisión / tarea | Mantenedor Alaira | Planner | Product | Arquitecto | Implementador | Revisor/QA | Seguridad |
|---|---|---|---|---|---|---|---|
| Visión y alcance | A | R | R | C | I | C | C |
| Baseline SRS/WBS | A | R | R | C | I | C | C |
| ADR de arquitectura | A | C | C | R | C | C | C |
| Asignación y reservas de worktrees | I | A/R | C | C | I | I | I |
| Código y pruebas de tarea | I | A | C | C | R | C | C |
| Revisión técnica independiente | I | A | C | C | I | R | C |
| Seguridad/cambio de permisos | A | R | C | C | C | C | R |
| Cambio financiero/baseline | A | R | C | C | I | C | C |
| Licencia OSS / distribución | A/R | C | C | C | I | C | C |
| Release público | A | R | C | C | I | R | R |

Una misma persona puede asumir funciones, pero la revisión de un trabajo no la realiza su implementador. La delegación de aprobación debe estar autorizada explícitamente y ser auditable. No confundir agente de IA con órgano responsable legal.
