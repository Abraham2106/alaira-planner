| Superficie | Origen |
|---|---|

Login deja el hash en `#/projects`, no en el ejemplo. Si la API falla: error, forbidden o sesión ausente. No se rellena con `exampleItems`.

El avance de un paquete es `progressPercent` del rollup. El de una hoja es el de esa hoja en el rollup. Si no hay un único paquete raíz, no se promedia: el número de proyecto queda vacío y cada nodo conserva el suyo. Un rollup de 40 con hojas 0 y 100 no se muestra como 50.

Responsable: solo el `displayName` si la asignación y la persona vuelven juntas. Peso: solo el `weight` de una hoja del rollup. Estrategia: la API no la devuelve al leer; tras un `PUT` exitoso se etiqueta «Confirmada al guardar» y se aclara que al recargar no reaparece.
